🖤 vampire.he4rt

«somewhere between midnight and nowhere.»

vampire.he4rt is my little corner of the internet, inspired by dark Y2K, cyber-goth aesthetics, and the old internet.

✦ Features

- 🦇 Dark cyber-goth design
- ♡ Home, Digital ID, and About sections
- 🪪 Custom Digital ID generator
- 🎀 Choose your mood and type
- 📋 Copy your generated ID
- 📱 Responsive layout for smaller screens

🛠️ Built With

- HTML
- CSS
- JavaScript

🚀 Run Locally

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open "index.html" in your browser.
